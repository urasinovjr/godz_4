# ДЗ 4. Интерфейсы и валидация в Ledger

Продолжение ДЗ 3. Gateway не менялся, в Ledger добавилась проверка данных через интерфейс.

## Что сделано в Ledger

В `validation.go` лежит интерфейс `Validatable` с методом `Validate() error` и функция `CheckValid`, в которую можно передать и транзакцию, и бюджет.

`Transaction.Validate()` не пропускает нулевую или отрицательную сумму и пустую категорию. `Budget.Validate()` проверяет, что лимит больше нуля и категория не пустая. `AddTransaction` и `SetBudget` сначала вызывают `Validate()` и при ошибке ничего не сохраняют, а печатает ошибку уже `main`.

## Запуск Ledger

Запускать из папки `ledger`, рядом должен лежать `budgets.json`:

```bash
cd ledger
go run .
```

В конце печатается список из 6 транзакций, отклоненных в нем нет.

## Запуск Gateway

```bash
cd gateway
go run .
```

Проверка из второго терминала, ответ `pong`:

```bash
curl http://localhost:8080/ping
```
